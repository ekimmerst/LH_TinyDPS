# LH TinyDPS

LH TinyDPS is a separate, compact display for the combat statistics supplied by the World of Warcraft: Forever client. It does not skin or replace the Blizzard damage meter frame. It requires LH Tweaks and appears beneath it in the AddOn list and the standard AddOns settings dialog. The AddOn icon is the LH Tweaks icon.

The initial window position is 16 UI units below `LH_StatsFrame` when LH Stats is loaded. Otherwise it appears below the minimap. A saved manual position takes precedence. The default window fits five bars and uses the Options dialog's panel background color and opacity with LH ExpBar's thin gold border. Empty rows stay hidden until combat data exists. The border setting offers no border, the thin LH ExpBar border, and the game's standard Options dialog border. Border color sliders affect the thin border; border opacity affects both styles. Unlock the window and left-drag it to move; drag the small circle below its right edge to resize. Lock it to keep the position and size. Right-click the window to open settings; middle-click resets the client's combat data. Mouse buttons 4 and 5 cycle combat sessions. The mouse wheel scrolls entries. All LH TinyDPS settings are saved per character.

The right side of the header has a `Heal`/`Dmg` button to switch views and a yellow trash-can button to clear all combat sessions. After a reset, the display returns to the overall view and the client records new combat automatically. Reset also clears data shown in Blizzard's own damage meter.

Settings cover damage/healing, current/overall/available historical sessions, window size, bar size and count, text layout and font, colors and opacity, visibility, tooltips, report length and the optional minimap button. By default, each row shows the first name and DPS or HPS while solo, or the source's share of total damage or healing while grouped. The optional rank appears to the left of the name. Turning off automatic values enables custom total, per-second and percent choices. The client includes pet damage in the owner's source total; the tooltip separates player and pet subtotals and abilities, showing exact amounts and percentages of that combined total. The button can be dragged around the minimap. Its left click toggles visibility, right click opens settings and middle click resets combat data. `/lh_tinydps` provides the same basic controls; `/lh_tinydps report whisper NAME` sends a report to a named player.

The game supplies the measurements through `C_DamageMeter`. LH TinyDPS does not parse combat logs or maintain its own fight history. The original TinyDPS options for retaining a chosen number of fights or retaining only boss fights cannot be reproduced through the available API. The game may protect combat values while fighting; percentage calculation and chat reports are limited to readable values. Resetting data clears the game's sessions for both displays.

In-game validation is still required, especially combat-time data presentation and the behavior when Blizzard's own window is disabled. The Blizzard window is left unchanged by LH TinyDPS.
